# خطوتي | Khotwati PWA

تطبيق عربي لتتبع مدة الابتعاد عن عدة عادات.

## المزايا
- عداد مباشر بالأيام والساعات والدقائق والثواني لكل عادة.
- إضافة وتعديل وحذف العادات، وتحديد وقت البداية والهدف والملاحظة.
- أهداف من أسبوع إلى سنة مع شريط تقدم.
- تسجيل الانتكاسة في السجل ثم بدء سلسلة جديدة، دون حذف التقدم السابق المسجل.
- تصدير نسخة احتياطية واستعادتها بصيغة JSON.
- واجهة خضراء وبيضاء، وأيقونات، وPWA قابل للتثبيت.

## التشغيل والتثبيت
1. فك ضغط الملف وارفع محتوياته إلى استضافة HTTPS مثل GitHub Pages أو Netlify.
2. افتح الموقع في متصفح الهاتف واختر «إضافة إلى الشاشة الرئيسية» أو «تثبيت التطبيق».
3. البيانات محفوظة محليًا في المتصفح على هذا الجهاز. خذ نسخة احتياطية بانتظام؛ حذف بيانات الموقع أو تغيير عنوانه قد يؤدي إلى فقدان البيانات.

يحتاج التثبيت وService Worker إلى HTTPS أو localhost.
